# 📚 Library Management System

A simple **terminal-based Library Management System** developed using **Python and Object-Oriented Programming (OOP)**.

The system allows users to manage books and student accounts, issue and return books, search for books, and view the borrowing details of students.

---

## ✨ Features

- 🔍 Search books by ID, title, author, or subject
- ➕ Deposit/Add new books
- 👤 Create student accounts
- 📖 Issue/Borrow books to students
- ↩️ Return books
- 📚 Display all books
- 🗑️ Remove books
- 👩‍🎓 View student borrowing details
- 📅 Track the date when a book was borrowed
- 📘 Track the subject of borrowed books
- 🔢 Track the number of books borrowed by a student
- ✅ Check book availability

---

## 🛠️ Technologies Used

- **Python**
- **Object-Oriented Programming (OOP)**
- **Dictionary**
- **Loops and Conditional Statements**
- **Date and Time**
